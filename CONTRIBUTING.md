# Contributing

Anyone can propose a change. A member of the `@VATSIM-Turkiye/ops-nav` team reviews it before it reaches `main`.

## Outside the organization

1. Fork the repository.
2. Create a branch from `main`.
3. Commit your change and open a pull request against `main`.
4. Leave **Allow edits by maintainers** enabled so a reviewer can push a small fix onto your branch.

## Organization members

Create a branch in this repository, push that branch, and open a pull request against `main`. A direct push to `main` is rejected.

You cannot approve your own pull request. Another member of `@VATSIM-Turkiye/ops-nav` has to approve it.

## What to include

- Say which airport, position, or plugin the change affects.
- For a EuroScope or sector-file bug, include a screenshot of the whole EuroScope window.
- Keep generated AeroNav package files out of this repository. Full sector-file releases stay on [AeroNav GNG](https://files.aero-nav.com/LTXX).
